# Venom Aid

ถ่ายรูปแผลหรือเล่าอาการ แล้วให้ AI ช่วยบอกว่าน่าจะโดนสัตว์มีพิษชนิดไหนกัด พร้อมแนวทางปฐมพยาบาลและสรุปข้อมูลให้แพทย์

- เปิด `index.html` ในเบราว์เซอร์เพื่อดูหน้าตาและคู่มือสัตว์มีพิษ
- การวิเคราะห์ด้วย AI ทำงานในเวอร์ชันที่เผยแพร่บน Claude: https://claude.ai/artifact/9xDNJQYSqzg5X1Xu3FKzhA
- รายละเอียดสำหรับพัฒนาต่ออยู่ใน `CLAUDE.md` แหล่งอ้างอิงอยู่ใน `docs/references.md`

> ข้อมูลในแอพใช้ปฐมพยาบาลเบื้องต้นเท่านั้น ไม่ใช่การวินิจฉัย ฉุกเฉินโทร 1669
